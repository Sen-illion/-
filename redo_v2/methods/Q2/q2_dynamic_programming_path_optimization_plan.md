# Q2 动态规划—候选路径降维优化方案

## 1. 目标与不变项

本方案在 Q2 已批准的“七年共享决策随机 MILP + CVaR 风险预算”之上进行求解架构优化。目标是利用 Q1 中已有的跨年度轮作、豆类覆盖和地块模式状态，将大量年度种植变量压缩为地块级七年候选路径，从而更快获得 incumbent、降低分支定界规模，并保留多情景共享决策含义。

以下数学含义不改变：

- 规划期仍为 2024--2030；
- 所有情景共享同一套事前种植决策；
- 年度变化率独立抽样，参数水平递推为 `X_t=X_{t-1}(1+r_t)`；
- Wasted 与 Half-price 超产规则分别求解；
- 主目标仍为 `max Σ_k w_k Π_k`；
- 风险约束仍为 `CVaR^-_{0.95}(Π) >= B`，等价损失形式为 `CVaR^+_{0.95}(-Π) <= κ`，且 `κ=-B`；
- 不引入目标函数中的 λ 权重。

## 2. 核心架构

采用“两层路径生成 + 共享情景主问题”：

1. 地块级 DP/beam search 生成每个地块的合法七年候选路径；
2. 主 MILP 只选择每个地块的一条路径，并对 K 个情景计算利润与 CVaR。

原始年度变量 `x_{i,t,s,c}, y_{i,t,s,c}` 不再全部进入主问题。对地块 `i` 和候选路径 `p` 定义：

`z_{i,p} ∈ {0,1}`，表示选择路径 `p`。

路径选择约束：

`Σ_{p∈P_i} z_{i,p}=1`。

路径本身预先满足：面积上下界、作物适宜性、同作物相邻轮作、豆类三年覆盖、灌溉地互斥模式和 2023 历史衔接。因此这些约束不再在主 MILP 中重复展开。

## 3. 地块级 DP 状态与转移

### 3.1 状态

对地块 `i` 在年度 `t` 使用压缩状态：

`S_{i,t}=(h_{i,t-2}, h_{i,t-1}, b_{i,t-2}, b_{i,t-1}, m_{i,t})`。

其中：

- `h` 是上一至前两期各季次的作物/空置编码，用于轮作；
- `b` 表示最近两年是否已满足豆类覆盖；
- `m` 是灌溉地单季水稻或双季蔬菜模式，其他地块为固定空值；
- 2023 实际种植记录作为初始状态。

状态中不保存情景编号；情景只用于评价路径的年度利润，因此不会复制状态空间 K 份。

### 3.2 年度动作

动作 `a_{i,t}` 是该地块当年的合法季次面积分配。对每个激活作物：

`α A_i <= x_{i,t,s,c} <= A_i`，其中 `α=0.10`。

同一季次面积和灌溉模式约束在动作生成阶段直接检查。对于缺失经济参数或不适宜组合，动作生成前直接删除。

### 3.3 转移和剪枝

状态转移为：

`S_{i,t+1}=f_i(S_{i,t},a_{i,t})`。

只保留满足以下条件的转移：

- 相邻年度同作物不重复；
- 任意连续三年豆类面积覆盖地块面积；
- 灌溉地模式不冲突；
- 最小面积和地块容量满足；
- 2030 结束状态满足终端轮作/豆类检查。

为控制状态数，使用 beam width `W∈{20,50,100}`，并按下列支配规则剪枝：同一状态下，若路径在所有已生成情景的累计利润不高于另一条路径且资源占用不低于另一条路径，则删除该路径；否则保留累计期望利润最高的前 W 条。

## 4. 候选路径评分与情景主问题

对每条路径 `p`、情景 `k` 预计算：

- 七年逐年产量、正常销售量、超产量；
- 七年总利润 `π_{i,p,k}`；
- 路径占用和可审计的轮作状态摘要。

主问题中的情景利润为：

`Π_k = Σ_i Σ_{p∈P_i} π_{i,p,k} z_{i,p}`。

目标：

`max Σ_k w_k Π_k`。

CVaR 约束保持线性形式：

`ξ_k >= -Π_k - η`，`ξ_k >= 0`，

`η + 1/(1-0.95) Σ_k w_k ξ_k <= κ`。

其中 `B=CVaR^-_{0.95}(Π_ref)`，`κ=-B`，参考方案固定且在实验摘要中记录。

Wasted 和 Half-price 分别构造 `π_{i,p,k}`，不可共享同一套超产规则结果。

## 5. 复杂度预期与参数档位

当前模型有 7,490 个共享二进制种植变量。若每地块保留 `P` 条路径，主问题路径二进制变量上界约为 `54P`：

| 路径数 P/地块 | 路径二进制变量 | 相对 7,490 的理论减少 |
|---:|---:|---:|
| 10 | 540 | 92.8% |
| 20 | 1,080 | 85.6% |
| 50 | 2,700 | 63.9% |

情景连续变量仍随 K 增加，但不再重复承载地块级轮作和豆类约束。首轮只比较 `P=10` 与 `P=20`，不直接恢复 K=20/40/60/80/100。

## 6. 实施阶段

### 阶段 A：DP 可行性与覆盖率

- 实现状态编码、动作生成、2023 历史衔接和终端验证；
- 对每个地块生成 `P=10/20` 条路径；
- 输出路径数量、状态数、剪枝率、Q1 约束违规数和路径收益分布；
- 若某地块无法生成路径，立即报告并停止，不自动切换方法。

### 阶段 B：路径主问题小规模验证

- 固定 K=1，分别运行 Wasted/Half-price；
- 对比原始 M1/M2 的目标、可行性、incumbent 时间和约束验证；
- 确认路径主问题与原始共享决策模型的 CVaR 公式完全一致。

### 阶段 C：K=5 消融复核

- 运行无 CVaR 与含 CVaR 两个版本；
- 统一 600 秒时限；
- 记录连续变量、路径二进制变量、约束、incumbent、best bound、MIP gap、node count 和求解时间；
- 只有 M4（K=5，含 CVaR）获得 incumbent，才考虑扩大 K。

### 阶段 D：正式情景实验

- 依次测试 K=20、40、60、80、100；
- 每个 K 同时保留普通 K-medoids 与尾部保护 K-medoids；
- 使用独立 N_test=2000 情景评价均值、Q05、CVaR、最差利润和约束违规；
- 固定随机种子并保存每类参数的独立抽样、递推累计和 seed 记录。

## 7. 正确性与等价性验收

每条候选路径必须通过 Q1 `validate_plan` 约束检查。主问题输出后再次展开路径并执行全量验证。验收条件：

1. 所有地块恰选一条路径；
2. 展开后的 `x/y` 方案满足 Q1 全部硬约束；
3. 情景利润逐项等于路径利润之和；
4. 手工计算的利润最低 5% 加权 CVaR 满足 `CVaR^-_{0.95}(Π) >= B`；
5. MILP 的 `η,ξ` 表达式与手工 CVaR 差值不超过 `1e-6`（金额缩放后按对应容差换算）；
6. 主模型不含 scenario-indexed binary，不使用 λ 风险权重；
7. 无 incumbent 时只写入失败诊断并暂停后续规模，不启用 Q2-F1。

## 8. 风险、退化与回退边界

- 候选路径过少会造成近似最优而非原始 MILP 全局最优；必须报告路径覆盖率和与 Q1 基准的差距；
- DP 只生成路径，不改变 CVaR 方向和预算映射；
- 若 `P=20` 仍无法覆盖合法状态，先增加 beam width 或路径数并重新验证；
- 只有在人类明确批准后，才可启用候选路径协调 fallback；本方案不自动切换求解方法。
