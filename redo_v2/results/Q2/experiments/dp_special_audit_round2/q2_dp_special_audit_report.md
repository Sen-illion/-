## 1. DP 豆类状态

**原实现/风险：** 若仅保存 `b_{t-2},b_{t-1}` 两个布尔值，则最近两年豆类面积分别为 `0.1A,0.1A` 与 `0.4A,0.4A` 的历史会被合并，但下一年满足三年覆盖所需面积分别为 `0.8A` 与 `0.2A`，合法动作集合不同。

**当前修正：** 状态保存

`(H_{t-2}, H_{t-1}, L_{t-2}, L_{t-1}, M_t)`，其中 `L` 是按 Q1 口径计算的实际豆类覆盖面积。每个滚动窗口检查

`L_{t-2}+L_{t-1}+L_t+F_t >= A_i`。

2023 历史用于初始化，2025—2030 逐年滚动检查，候选路径展开后调用 Q1 `validate_plan`。

**结果：** 54 个地块、P=2 的 108 条候选路径均生成成功；完整方案 `violation_count=0`。数学含义与 Q1 面积型约束等价，只有状态表示被修正。

**结论： PASS**

## 2. 销量与利润可加性

### 原实现问题

Q1 的需求上限是作物—年度的全村共享上限，而旧路径主模型将不同季次/价格来源压成一个代表价格，可能无法保持 Q1 的逐来源正常销售线性化。

### 当前修正

路径阶段只输出可加量：面积、作物—年度—季次产量贡献和成本。主 MILP 对每个情景先按 `(作物, 年, 季次, 情景价格)` 汇总产量，建立对应正常销售变量 `u_g`，再施加统一的作物—年度需求约束：

`Σ_g u_{c,t,g} <= D_{c,t}`，`u_g <= Q_g`。

Wasted 收入为 `Σ_g p_g u_g`；Half-price 收入为 `Σ_g [0.5 p_g Q_g + 0.5 p_g u_g]`。最终情景利润为全村销售收入减全村路径成本，不再把各地块最终利润独立相加。

### 反例

`D=100, Q_A=80, Q_B=80` 时，模型聚合得到 `Q=160, u=100, excess=60`；价格为 1 时 Wasted 收入为 100，Half-price 收入为 130，而不是正常销售 160。

### 等价性

该修正恢复了 Q1 的全村需求耦合和季次价格口径；相对于旧的单一代表价格写法，属于必要的数学修正，不是放松约束。

**结论： PASS**

## 3. CVaR

保持

`B = CVaR^-_0.95(Pi_ref)`，`kappa=-B`，

`xi_k >= -Pi_k-eta`，`eta + 1/0.05 Σ w_k xi_k <= kappa`，无 lambda。

K=5、P=2、seed=2026 的回归运行中，Wasted 和 Half-price 均获得 incumbent，且方案 `violation_count=0`。K=5 的尾部解释仍受代表情景权重限制，不能作为正式尾部刻画。

**结论： PASS**
