# 问题二提交版表述

## 1. 建模思路

问题二要求在销量、亩产量、种植成本和销售价格均存在年度不确定性的条件下，给出 2024—2030 年的统一种植方案。由于种植决策在不确定参数实现前确定，所有情景必须共享同一套种植决策；销量和收益则在情景实现后统一计算。

首先采用 Monte Carlo 方法生成 1000 条 2024—2030 年完整随机轨迹，并使用加权 K-medoids 对情景进行缩减。对于年度变化参数，年度变化率独立抽样，但参数水平按照递推关系逐年累积：

\[
X_t=X_{t-1}(1+r_t),\qquad t=2024,\ldots,2030.
\]

在此基础上，对每个地块建立动态规划状态。状态保存最近两期的轮作作物信息、最近两年的实际豆类种植面积以及灌溉地种植模式。豆类约束采用面积型三年滚动覆盖：

\[
L_{i,t-2}+L_{i,t-1}+L_{i,t}+F_{i,t}\ge A_i,
\]

其中 (L_{i,t}) 为地块 (i) 在第 (t) 年的豆类种植面积，(F_{i,t}) 为 2023 年历史种植在当前窗口中的固定贡献，(A_i) 为地块面积。动态规划通过状态转移和 beam search 为每个地块生成 20 条合法的七年候选路径，路径在生成阶段即满足轮作、豆类覆盖、面积、适宜性和灌溉模式约束。

随后建立路径选择主问题。令 (z_{i,p}\in\{0,1\}) 表示地块 (i) 是否选择候选路径 (p)，则：

\[
\sum_{p\in\mathcal P_i}z_{i,p}=1.
\]

所有情景共享同一组 (z_{i,p})。对情景 (k)，先汇总全村各作物—年度产量：

\[
Q_{c,t,k}=\sum_i\sum_{p\in\mathcal P_i}q_{i,p,c,t,k}z_{i,p}.
\]

正常销售量在全村作物—年度层面统一计算，而不是让各地块分别使用完整销量上限。设 (D_{c,t,k}) 为情景 (k) 下的销量上限，则：

\[
0\le u_{c,t,k}\le Q_{c,t,k},\qquad
u_{c,t,k}\le D_{c,t,k}.
\]

Wasted 规则下，超出部分不产生收入；Half-price 规则下，超出部分按正常价格的 50% 计入收入。

主目标为最大化加权期望利润：

\[
\max \sum_k w_k\Pi_k.
\]

风险控制采用 CVaR 硬约束，而不是目标函数中的风险权重。定义损失 (L_k=-\Pi_k)，\(\beta=0.95\)，并令：

\[
B=CVaR^-_{0.95}(\Pi^{\rm ref}),\qquad \kappa=-B.
\]

其线性化形式为：

\[
\xi_k\ge-\Pi_k-\eta,\qquad \xi_k\ge0,
\]

\[
\eta+\frac{1}{1-0.95}\sum_kw_k\xi_k\le\kappa.
\]

因此模型等价于：

\[
CVaR^-_{0.95}(\Pi)\ge B.
\]

本模型不引入 \(\lambda\) 风险权重。

## 2. 参数与实验设置

训练情景数为 1000，独立测试情景数为 2000；训练随机种子为 2026，测试随机种子为 3026；每个地块保留 20 条候选路径，beam width 取 50。情景缩减规模分别取 (K=20,40,60,80,100)，Wasted 与 Half-price 两种超产处理规则分别求解。

## 4. 结果分析与方案选择

在所有情景缩减规模下，Half-price 规则的样本外平均利润、5% 分位利润、下尾 CVaR 和最差利润均明显高于 Wasted 规则。因此，在题目允许超产按 50% 正常价格销售的条件下，建议将 Half-price 结果作为问题二的主方案，将 Wasted 结果作为保守对照方案。

以 (K=100) 为代表，Half-price 主方案在 2000 条独立测试情景下的平均利润为 29,737,630.66，5% 分位利润为 28,573,907.14，下尾 CVaR 为 28,278,173.86，最差利润为 27,645,632.35，农业约束违规数为 0。相应的 Wasted 对照方案平均利润为 13,679,507.14，下尾 CVaR 为 13,268,946.52。

随着 (K) 从 20 增加到 100，Half-price 方案的平均利润在约 29.36—29.88 百万元之间波动，5% 分位利润和下尾 CVaR 也保持稳定，说明情景缩减规模变化未造成明显的结果失稳。

## 5. 提交时的表格与说明

正文中应将 Half-price 方案作为主结果，列出 2024—2030 年各地块、各季次和各作物的种植面积；Wasted 方案作为规则对照列出总体收益和风险指标。附件表格应包含 `plot_id`、`year`、`slot`、`crop_id` 和 `area` 五列，并将未种植组合记为 0。

需要说明的是，本文采用 DP 候选路径集，因此得到的是受限路径集上的最优组合，而不是原始完整 MILP 全局最优性的严格证明。MIP gap、路径数和独立样本外评价应作为结果可信度和局限性说明的一部分保留。
