# Q2 动态规划候选路径随机 MILP 最终实验报告

## 方法

采用 `N_raw=1000`、K-medoids 情景缩减、地块级 DP/beam search 七年候选路径、全村路径选择共享决策 MILP、全局销量聚合和 CVaR 硬约束。规划期为 2024--2030，训练 seed=2026，独立测试 seed=3026、2000 情景。路径档位为每地块 P=20、beam width=50。

目标和风险约束保持：

`max Σ_k w_k Π_k`，

`CVaR^-_0.95(Π) >= B`，等价损失形式 `CVaR^+_0.95(-Π) <= κ`，`κ=-B`。未引入 lambda。

## 核验结论

- 54 个地块均生成 20 条 DP 路径；路径覆盖完整，所有展开方案硬约束违规数为 0。
- 情景利润按全村作物—年度先聚合产量，再统一施加需求上限；没有地块级重复使用销售上限。
- Wasted 与 Half-price 独立求解，未共享超产收入公式。
- 所有正式模型均获得 incumbent；没有启用 fallback。
- K=20--100 的正式实验全部完成，独立测试集为 2000 个新情景。
- Half-price 的样本外收益显著高于 Wasted；K 增大后指标有小幅波动，未出现硬约束失效。

## 局限

DP 路径法优化的是受限候选路径集，不构成原始完整 MILP 全局最优性的证明。后续论文应报告 P=10/20 路径稳定性、MIP gap 和候选路径近似局限，不应把 `status=0` 或 incumbent 解释为严格全局最优。
