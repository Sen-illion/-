# Q2 DP 路径模型专项结构审查报告

## 总结

本轮在不改变 Q2 总体路线、农业硬约束、Wasted/Half-price 规则、CVaR 方向和无 lambda 原则的前提下，完成了 DP 路径原型与 K=5 路径主问题验证。

总体状态：

- DP 豆类状态：PASS（使用最近两年实际豆类面积，而不是布尔标记）；
- 路径候选硬约束：PASS（54 个地块、108 条候选路径的抽样展开验证为 0 违规）；
- 销量/利润全局聚合：PASS（主问题按作物—年度全村汇总，未在地块级重复使用需求上限）；
- CVaR 公式与预算方向：PASS（仍为 `kappa=-B`）；
- K=5 求解性能：PASS（M3-DP/M4-DP 均获得 incumbent）；
- 候选路径近似的最优性覆盖：NEEDS FIX（目前仅使用小路径档位，尚未完成 P=10/20/50 全量覆盖比较）。

## 一、DP 豆类状态审查

### 原实现与问题

原方案概念状态使用：

`S=(h_{t-2},h_{t-1},b_{t-2},b_{t-1},m_t)`，其中 `b` 仅表示是否种过豆类。

Q1 实际约束是面积型：

`sum_{tau=t-2}^t bean_area_{i,tau} + history_fixed >= A_i`。

相同布尔状态可能对应最近两年豆类面积分别为 `0.2A_i` 和 `0.8A_i`，下一年所需豆类面积不同，因此布尔状态会错误合并。

### 修正

当前 DP 状态保存：

`S=(H_{t-2},H_{t-1},L_{t-2},L_{t-1},M_t)`，其中 `L` 为实际豆类面积。

每个 2025--2030 动作均检查：

`L_{t-2}+L_{t-1}+L_t+F_t >= A_i`。

2023 历史记录用于初始化；路径最终再次展开为原始 `x/y` 形式并调用 Q1 `validate_plan`。

### 结果与等价性

本轮生成 54 个地块、108 条候选路径；所有地块均非空。以每地块第一条路径组成完整方案，调用 Q1 `validate_plan` 得到：

`violation_count = 0`。

因此，面积型豆类状态修正保持原 Q1 约束含义等价；候选路径集本身仍是受限近似，不自动等价于原始 MILP 的全局最优路径集合。

## 二、销量与利润可加性审查

### 原实现与问题

Q1/Q2 销量约束的需求上限按作物—年度在全村聚合：

`sum_i,s u_{i,t,s,c} <= D_{c,t}`。

因此不能让每个地块在 DP 阶段独立使用完整 `D_{c,t}` 计算正常销售和超产，再把地块利润相加；这会重复使用销售上限。

### 修正

DP 只输出严格可加的路径贡献：

- 种植面积；
- 每个作物—年度的产量贡献；
- 种植成本。

路径主问题先汇总：

`Q_{c,t,k}=sum_{i,p} q_{i,p,c,t,k} z_{i,p}`。

再在全村层面统一计算：

`u_{c,t,k} <= Q_{c,t,k}`，`u_{c,t,k} <= D_{c,t,k}`。

Wasted 收入为 `p*u`；Half-price 收入为 `p*u+0.5p*(Q-u)`；最终利润为全局销售收入减全村路径成本。

### 最小反例

设同一作物总需求 `D=100`，A/B 两地块产量分别为 80：

`Q=80+80=160`，`u=min(160,100)=100`，`E=160-100=60`。

Wasted：`R=100p`；Half-price：`R=100p+60*0.5p=130p`。

这排除了错误的“两个地块分别正常销售 80、总正常销售 160”。该逻辑已直接写入 `q2_path_master.py` 的全局作物—年度汇总结构。

### 等价性

与 Q1 的全村共享需求约束数学含义等价；改变的只是将地块级决策先压缩为路径，再在主问题统一销售，不再错误拆分利润。

## 三、CVaR 审查

### 保持的公式

固定参考方案得到：

`B=CVaR^-_0.95(Pi_ref)`，`kappa=-B`。

主问题保持：

`xi_k >= -Pi_k-eta`，`xi_k >= 0`，

`eta + (1/0.05) sum_k w_k xi_k <= kappa`。

目标仍为 `max sum_k w_k Pi_k`，没有引入 lambda。

### K=5 诊断

K=5 缩减权重为 `[0.241,0.232,0.201,0.129,0.197]`；最差代表情景权重为 `0.129`，已经超过 5%。因此 K=5 的利润最低 5% 尾部完全落在最差代表情景内部，CVaR 实际退化为最差代表情景利润。K=5 仅用于诊断，不能作为最终 95% 尾部刻画。

### 等价性

路径模型只改变种植决策表示，不改变 `Pi_k` 的全村定义和 CVaR 线性化，故 CVaR 数学含义保持等价。

## 四、求解性能

固定 K=5、随机种子 2026、路径数 2/地块、beam width 10、600 秒时限。修正 Half-price 全局利润系数后：

| 模型 | binary | continuous | constraints | incumbent | gap | time |
|---|---:|---:|---:|---|---:|---:|
| M3-DP，无 CVaR | 108 | 1,440 | 2,929 | 是 | 4.5443% | 0.0650 s |
| M4-loose，CVaR 不绑定 | 108 | 1,446 | 2,935 | 是 | 0.0637% | 0.0380 s |
| M4-DP，正式 CVaR | 108 | 1,446 | 2,935 | 是 | 0.0252% | 0.0413 s |

原始 K=5 模型为 7,490 个二进制变量、约 600 秒仍未获得 CVaR incumbent。路径主问题将共享种植二进制变量从 7,490 降到 108，减少约 98.6%。M4-loose 与正式 M4-DP 均快速得到 incumbent，说明在路径降维后，当前 CVaR 辅助结构本身不再是主要计算瓶颈；正式风险底线也未造成额外显著困难。

## 五、最终结论

- DP 豆类状态：PASS；
- 全局销量聚合：PASS；
- CVaR 公式、方向和 `kappa=-B`：PASS；
- K=5 路径主问题求解可行性：PASS；
- 路径候选集合对原始全局最优的覆盖：NEEDS FIX；
- 正式 K=20/40/60/80/100：本轮未运行，继续保持暂停。

下一阶段应先增加路径档位 `P=10/20` 并做路径覆盖率、目标值和样本外风险比较；只有路径质量稳定且 K=5 含 CVaR 持续获得 incumbent，才恢复正式大 K 实验。
