# 全题初步建模与执行地图

状态：`DRAFT`（全题初步模型已建立；当前只激活 Q1）

## 1. 共同问题结构

Q1–Q3 的共同决策都是 2024–2030 年逐地块、逐季、逐作物的种植面积。三问共享地块容量、适种范围、轮作、三年豆类覆盖和管理便利性约束；差别主要在未来经济参数与风险表达。

统一决策变量为种植面积 $x_{ijts}\ge 0$ 和启用指示 $y_{ijts}\in\{0,1\}$。产量由面积与亩产相乘，销售量受预期销量上限约束，利润等于销售收入减种植成本。全部单位统一为亩、斤、元/亩和元/斤。

## 3. 依赖与执行顺序

依赖链为 `Q1 → Q2 → Q3`。Q2 复用 Q1 的可行域和确定性基准；Q3 复用 Q2 的不确定性边际、评价指标和基准方案。因此当前采用逐问顺序，不把 Q2、Q3 与 Q1 一次求解。

Q2 与 Q3 属于强关联但不宜同时运行的问题组：两者可以共同设计情景接口，Q3 只在 Q2 的边际分布和基准结果确认后增加相关结构。这样能把“处理不确定性”的收益与“加入相关性”的增量影响分开识别。
